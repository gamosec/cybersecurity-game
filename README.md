# غرفة الهروب السيبرانية — Cyber Security Escape Room (Arabic)

لعبة تعليمية بلغة HTML5 باللغة العربية (RTL) للتوعية بالأمن السيبراني. يستكشف اللاعب غرفة متساوية القياس (Isometric)، ويكتشف العناصر التي تشكّل خطرًا على أمن المعلومات، ويختار المخاطر المرتبطة بكل عنصر قبل نفاد الوقت.

An Arabic, browser-based cyber-security awareness escape-room game. Pure HTML/CSS/JS with no build step and no dependencies. All artwork is drawn in code as SVG.

## التشغيل / Running

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```bash
python3 -m http.server 8000   # ثم افتح http://localhost:8000
```

## طريقة اللعب والنقاط / Gameplay & scoring

- لكل إجابة صحيحة بالكامل (تحديد كل المخاطر الصحيحة فقط): **50 نقطة**.
- مكافأة الوقت: حتى **30 نقطة** تتناسب مع الوقت المتبقي (`round(remaining / limit × 30)`).
- الدرجة القصوى لكل سيناريو: **280 نقطة** (5 × 50 + 30). الوقت: **02:15** للسيناريو 1 و**02:30** لبقية السيناريوهات.
- زر الجرس 🔔 يُظهر تلميحًا بالعناصر المتبقية، وزر ❓ يعرض التعليمات (ويتوقف المؤقت أثناء القراءة).
- تُحفظ أفضل نتيجة لكل سيناريو في `localStorage`.

## إضافة سيناريو جديد / Adding a scenario

> الأسرع: `node tools/new-scenario.js <slug> <رقم> "<العنوان>" "<العنوان الفرعي>"` ثم أكمل الـ TODO (التفاصيل في [`docs/CONTENT-GUIDE.md`](docs/CONTENT-GUIDE.md)). البنية اليدوية:

1. أنشئ ملفًا في `js/scenarios/` وأضفه في `index.html` قبل `js/game.js`.
2. سجّل السيناريو:

```js
CyberEscape.registerScenario({
  id: 'phishing',               // معرّف فريد
  number: 2,
  kicker: 'تحديات الأمن السيبراني',
  heading: 'صندوق البريد المشبوه',
  title: 'رسائل التصيّد الاحتيالي',
  description: 'وصف قصير يظهر في شاشة البداية',
  timeLimit: 150,               // بالثواني
  pointsPerChallenge: 50,
  timeBonusMax: 30,
  passRatio: 0.6,               // نسبة النجاح المطلوبة
  viewBox: '0 0 1600 900',
  isoOrigin: [800, 300],        // موضع زاوية الغرفة الخلفية على الشاشة
  challenges: [
    {
      id: 'email',
      title: 'رسالة بريد من مرسل مجهول',
      options: [
        { text: 'التصيّد الاحتيالي', correct: true },
        { text: 'نفاد مساحة التخزين', correct: false }
      ],
      feedback: { summary: '...', tips: ['...', '...'] }
    }
  ],
  renderScene(iso) {
    // أعد سلسلة SVG. ضع العناصر القابلة للنقر داخل <g data-hotspot="email">.
    // يمكن تكرار data-hotspot نفسه في أكثر من مجموعة (مثلاً جزء خلف الطاولة وجزء أمامها).
    // تُنشأ منطقة نقر مستطيلة تلقائيًا؛ أضف data-hit="self" وعناصر class="hit" لتحديدها يدويًا.
    return iso.box(100, 100, 0, 80, 60, 70, '#4aa0da') +
      '<g data-hotspot="email">' + iso.box(120, 110, 70, 40, 30, 4, '#2f3b48') + '</g>';
  },
  renderIntroArt() { return '<svg viewBox="0 0 800 900">...</svg>'; } // اختياري
});
```

**قواعد المحتوى (لكل السيناريوهات):**
- لكل عنصر **4 خيارات**، وعدد الإجابات الصحيحة يختلف بين العناصر (1، 2، 3 أو الكل). لا تُحتسب الإجابة إلا إذا طابقت تمامًا.
- الخيارات الخاطئة تهديدات حقيقية لكنها لا تنطبق على العنصر (مثل "هجوم القوة الغاشمة" لكلمة مرور مكتوبة)، وليست خيارات سخيفة يسهل استبعادها.
- يُخلط ترتيب الخيارات تلقائيًا في كل مرة.
- `isNew: true` يُظهر شارة "جديد" على بطاقة السيناريو في القائمة.
- العملة: **الدينار** افتراضيًا، و**الدولار** فقط للخدمات الدولية (مثل اشتراك موقع عالمي).

**ملاحظات للرسم:** المحور `x` يتجه أسفل اليمين، و`y` أسفل اليسار، و`z` للأعلى. الجدار الأيسر هو `x = 0` والأيمن `y = 0`. استخدم `iso.onPlaneX / onPlaneY / onPlaneZ` لرسم صور مسطحة (لوحات، شاشات، أوراق) على الجدران والأسطح. ابدأ معرّفات التدرجات بمعرّف السيناريو (مثل `s2-`) لتجنّب التكرار.

## إضافة مهمة تفاعلية / Adding a mission

المهمة نوع مختلف عن سيناريو الغرفة: يجد اللاعب **محطة الفريق الأحمر** (جهاز أحمر) فيخوض تحديات بعقلية المهاجم على مستوى **التوعية** (اختيار نوع الأسلوب لفهم الثغرة، دون تفاصيل تنفيذية)، ثم ينتقل إلى **محطة الفريق الأزرق** ليبني الدفاعات بالسحب والإفلات. كل تغذية راجعة تعيد التركيز إلى الدرس الدفاعي.

```js
CyberEscape.registerScenario({
  id: 'my-mission', number: 8, type: 'mission', isNew: true,
  title: '...', heading: '...', description: '...',
  timeLimit: 360, pointsPerChallenge: 50, timeBonusMax: 50, passRatio: 0.6,
  viewBox: '0 0 1600 900', mobileViewBox: '240 110 1120 760', isoOrigin: [800, 300],
  briefing: { title: 'مقدمة', paragraphs: ['...', '...'] },
  switchText: 'نص الانتقال من الفريق الأحمر إلى الأزرق',
  teams: {
    red: {
      title: 'الفريق الأحمر', intro: '...',
      find: 'ابحث في المكتب عن محطة عمل ... (دون ذكر لونها)',
      hint: 'وصف للمكان فقط (التلميح الأول)',
      email: { from: '...', address: '...@example', subject: '...', body: ['...', '...'] },
      challenges: [ /* ui: 'select' */ ]
    },
    blue: { /* ... challenges بـ ui: 'dnd' */ }
  },
  // التحدي: { id, label, ui: 'select' | 'dnd', prompt, instruction?, options: [{ text, icon?, correct }], feedback: { summary, tips } }
  renderScene(iso) { /* ارسم المحطات داخل <g class="m-st" data-station="red|blue|decoy" data-name="..."> وفيه <polygon class="hit"> لمنطقة النقر، ومعها محطات تمويه */ },
  renderIntroArt() { return '<svg>...</svg>'; }
});
```

- **الخيارات المصورة:** كل خيار يظهر كبطاقة بأيقونة مرسومة. يمكن تحديد الأيقونة بـ `icon: 'doc+lock'` (رسم + شارة)، وإلا تُختار تلقائيًا من نص الخيار.
- **السحب والإفلات (`dnd`):** يعمل بالسحب على الحاسوب، وبالنقر لنقل الخيار إلى الصندوق وإعادته على الهاتف.
- **تسلسل الشاشة:** بعد النقر على المحطة الصحيحة تظهر رسالة بريد من قائد الفريق (إغلاقها بالضغط على ✕ أو "متابعة") ثم التحديات على شاشة حاسوب.
- **محطات التمويه:** النقر عليها يعطي رسالة "ليست محطة عمل ... واصل البحث" مع اسم صاحب المحطة.
- **النقاط:** 50 لكل تحدٍ مطابق تمامًا، ومكافأة الوقت **فقط عند اجتياز المهمة**. عند الفشل تظهر مراجعة لكل إجابة مع الصحيح، ويُطلب إعادة المحاولة.
- المؤقت يعمل أثناء البحث والإجابة، ويتوقف أثناء قراءة المقدمة والتغذية الراجعة.

## مكتبة الأيقونات المصورة

`js/icon-lib.js` يرسم أيقونات مسطحة بألوان زاهية: **رسم أساسي + شارة** (مثل `doc+eye`، `phone+shield`، `lock+hash`).

- الرسوم الأساسية: `doc mail phone handset monitor laptop person agent boss thief tech users door cloud wifi wifiTwin key lock unlock shield shieldCrack bug server house plane camera mic usb disk card bank cart network keypad tv bubble tag note link qr cap box zip exe db gear chip target org mitm mask hook bolt eyeBig keyboard printer folder trash`
- الشارات: `alert x check eye mag bolt hook dollar q up down out lock shield stop bug hash`
- `CyberEscape.Icons.get('doc+lock')` يعيد SVG، و`CyberEscape.Icons.forText(نص)` يختار الأيقونة المناسبة تلقائيًا من نص الخيار (قواعد في `rules`). **كل نص خيار جديد** يجب أن تطابقه قاعدة؛ وإلا حدّد `icon:` يدويًا أو أضف قاعدة.
- تظهر الخيارات في سيناريوهات الغرفة كبطاقات مصورة (2×2)، وفي المهام كبطاقات أكبر.

## النشر / Deploying

يُنشر الموقع تلقائيًا عبر GitHub Pages من الفرع `main`. عند كل تحديث، **ارفع رقم الإصدار** `?v=` في روابط CSS و JS داخل `index.html` (مثلًا من `v=13` إلى `v=14`؛ الفاحص `tools/check-content.js` يفرض تطابقها) حتى تتجاوز المتصفحات النسخ المخزنة مؤقتًا.

## إضافة رحلة تفاعلية / Adding a journey

الرحلة (`type: 'journey'`) عالم واحد كبير (مثل مقهى) تتحرك فيه الكاميرا بين **مشاهد** متتابعة؛ في كل مشهد يضغط اللاعب على عنصر مضيء في العالم ثم يجيب. أنواع المشاهد: `choice` (بطاقات مصورة + جهاز: مكالمة/كاميرا)، `items` (اختر الأغراض التي تأخذها)، `wifi` (قائمة شبكات + مفتاح VPN). المثال الكامل: `js/scenarios/journey1-cafe.js`، والتفاصيل في `docs/CONTENT-GUIDE.md` (القسم ز) و`docs/ARCHITECTURE.md` (القسم 5.1).
